🎯 90-Day Action Plan
⚡ Immediate (0-30 days) · Survival
  • Cut burn to $22K/mo — freeze outsourcing, drop non-core AI tools, pause hires → runway back to 8-9 mo.
  • Start fundraising — angel round $300-500K.
  • Collect AR + annual-prepay discount — chase >60d overdue; 15% discount for annual prepay.
📈 Mid (30-60 days) · Fix Unit Economics
  • Price test — +20% on core plan, watch 2 weeks.
  • Focus on high-NDR segments — target NDR >110%.
  • Cut CAC — stop inefficient ads, shift to content/referrals.
🏛️ Decisive (60-90 days)
  • Negotiate term sheet — model dilution; set red lines first.
  • Or breakeven plan — if funding fails, execute a healthy cost structure.
  • Board pack — P&L, cash, forecast, asks.
